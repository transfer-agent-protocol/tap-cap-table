# Install dependencies

You'll need these installed to start building:

- [Docker](https://docs.docker.com/get-docker/) — runs MongoDB and the API server locally
- [Foundry](https://getfoundry.sh/) — compiles and deploys the Solidity contracts

```bash
curl -L https://foundry.paradigm.xyz | bash
```

- [Node.js](https://nodejs.org/en/download/) — required to run the server and app
- [pnpm](https://pnpm.io/installation) — the package manager used throughout this project
- [MongoDB Compass](https://www.mongodb.com/try/download/compass) — optional GUI for inspecting the database during development

## Pull the repo

```bash
git clone --recurse-submodules https://github.com/transfer-agent-protocol/tap-cap-table.git
cd tap-cap-table
pnpm install
```

<Callout type="info">
Missing submodules: `git submodule update --init --recursive`.
</Callout>

## Who deploys what?

| Actor | Onchain surface |
| --- | --- |
| **Protocol builder** | Ships contracts (BUSL). Owns the shared **demo** factory on Plume if you reuse it. |
| **Transfer agent** | Deploys **their own** `CapTableFactory` — their book of business (many issuer tables). |
| **Issuer / admin wallet** | Calls `createCapTable` on a factory; becomes ADMIN of that issuer’s cap table. |

Mongo’s `factories` collection is only a **local mirror** of which factory address this stack talks to. Registering a factory in Mongo does not grant onchain ownership.
