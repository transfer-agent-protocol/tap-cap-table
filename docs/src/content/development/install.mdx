# Install dependencies

You'll need these installed to start building:

- [Git](https://git-scm.com/downloads) to clone the repo and its submodules (the OCF schemas and Solidity libraries).
- [Docker](https://docs.docker.com/get-docker/) with Compose v2 (`docker compose`) to run MongoDB and the API server.
- [Node.js 24](https://nodejs.org/en/download/) to run the server, app, and docs. The Docker images use `node:24-slim`.
- [pnpm 10](https://pnpm.io/installation), the package manager for the monorepo. `package.json` pins `pnpm@10.18.2`.
- [Foundry](https://getfoundry.sh/) to compile, test, and deploy the contracts. Install `foundryup`:

  ```bash
  curl -L https://foundry.paradigm.xyz | bash
  ```

  The repo pins Foundry v1.8.3. `pnpm setup` installs that version and builds the contracts, and bootstrap runs it for you when the contracts aren't built yet.
- Python 3, only for deploying a factory. `scripts/deployFactory.sh` uses it to read env files.
- [MongoDB Compass](https://www.mongodb.com/try/download/compass), optional, to browse the database.

Check the required tools:

```bash
git --version
docker compose version
node --version
pnpm --version
forge --version
python3 --version
```

## Pull the repo

```bash
git clone --recurse-submodules https://github.com/transfer-agent-protocol/tap-cap-table.git
cd tap-cap-table
pnpm install
```

<Callout type="info">
Cloned without submodules? Run `git submodule update --init --recursive`.
</Callout>

## Learn the structure

| Folder | What it holds |
| --- | --- |
| `app/` | Next.js product app (`/app`) and the landing page |
| `chain/` | Foundry project: contracts in `chain/src`, tests in `chain/test`, the deploy script in `chain/script` |
| `server/` | Express API, MongoDB models, and the event poller |
| `packages/units/` | `@tap/units`: the ×1e10 scaling and UUID ↔ bytes16 helpers shared by the app and server |
| `ocf/` | OCF JSON schemas (a git submodule) |
| `scripts/` | `bootstrap-plume.sh` (`pnpm bootstrap`), `deployFactory.sh` (`pnpm deploy-factory`), and dev helpers |
| `docs/` | This site |
