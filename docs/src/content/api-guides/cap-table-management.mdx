# Manage Cap Table

Use this section after first-time setup, when you need supporting records, an optional acceptance event, or a read of current holdings.

Product workspace: `/app/companies/<issuerId>`. For first-time setup, use [Create Stock Class](/development/create-stock-class), [Create Stakeholder](/development/create-stakeholder), and [Issue Stock](/development/issue-stock).

## Choose a page

| If you want to... | Go to | Outcome |
| --- | --- | --- |
| Save legends, plans, or update stakeholder wallets | [Add Supporting Records](/api-guides/cap-table-management/supporting-records) | Supporting records saved or wallet linked to a stakeholder. |
| Record acceptance after an issuance | [Issue and Accept Stock](/api-guides/cap-table-management/accept-stock) | Standalone `stockAcceptance` event for an existing `security_id`. |
| See who currently holds stock for an issuer | [View Cap Table](/api-guides/cap-table-management/view-cap-table) | Active stock positions, stock classes, and the issuer record. |
