# Manage Issuer

Use this section when the issuer already exists and you only need to register, audit, or extend its history. For first-time issuer creation, use [Create an Issuer](/development/cap-table-deploy).

## Choose a page

| If you want to... | Go to | Outcome |
| --- | --- | --- |
| Add a TAP record for a cap table that was already deployed | [Register Issuer](/api-guides/issuer-management/register-issuer) | TAP issuer record linked to the existing onchain cap table. |
| Check whether a stock action or share adjustment was recorded | [View History](/api-guides/issuer-management/read-history) | List of historical transactions for the issuer. |
| See which routes create a new history entry vs. save data only | [Add New History](/api-guides/issuer-management/history-routes) | Reference of routes by behavior. |
