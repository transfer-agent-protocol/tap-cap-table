# Corporate Actions

Use this section after the first stock issuance, when you need to change holdings or save supporting data for later transactions.

## Choose a page

| If you want to... | Go to | History row? |
| --- | --- | --- |
| Transfer, cancel, retract, reissue, or repurchase shares; adjust authorized shares | [Transfer, Cancel, and Reissue Stock](/api-guides/corporate-actions/transfer-cancel-and-reissue-stock) | Yes, after polling. |
| Save options, RSUs, CSAR/SSAR, SAFEs, or notes | [Save Equity Compensation and Convertibles](/api-guides/corporate-actions/equity-compensation-and-convertibles) | No — record only. |
| Save 409A valuations, vesting terms, legends, or stock plans | [Save Valuations and Terms](/api-guides/corporate-actions/valuations-and-terms) | No — record only. |

## Not available through TAP today

- Stock conversion and stock class split exist in the OCF model but have no public create routes.
- Stock consolidation is not exposed at all.
