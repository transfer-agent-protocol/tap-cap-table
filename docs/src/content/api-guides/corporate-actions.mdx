# Corporate Actions

These guides change stock after it's issued and record the terms and instruments around it. Onchain actions sign with the server key, which needs the role shown; see [Server-signed routes](/api-reference#server-signed-routes). Every onchain action adds history rows, and the MongoDB-only records don't.

| Action | Route | Role | Guide |
| --- | --- | --- | --- |
| Transfer stock | `POST /transactions/transfer/stock` | OPERATOR | [Transfer Stock](/development/transfer-stock) |
| Cancel, retract, reissue, or repurchase a security | `POST /transactions/<action>/stock` | OPERATOR | [Transfer, Cancel, and Reissue Stock](/api-guides/corporate-actions/transfer-cancel-and-reissue-stock) |
| Change issuer or stock class authorized shares | `POST /transactions/adjust/issuer/authorized-shares`, `POST /transactions/adjust/stock-class/authorized-shares` | ADMIN | [Adjust authorized shares](/api-guides/corporate-actions/transfer-cancel-and-reissue-stock#adjust-authorized-shares) |
| Record options, RSUs, SARs, SAFEs, or convertible notes | `POST /transactions/issuance/equity-compensation`, `POST /transactions/issuance/convertible` | None (MongoDB only) | [Equity Compensation and Convertibles](/api-guides/corporate-actions/equity-compensation-and-convertibles) |
| Record a 409A valuation, vesting terms, or a stock plan | `POST /valuation/create`, `POST /vesting-terms/create`, `POST /stock-plan/create` | None (MongoDB only) | [Valuations and Terms](/api-guides/corporate-actions/valuations-and-terms) |

OPERATOR means OPERATOR or ADMIN. OCF also defines stock conversions, class splits, and consolidations, which TAP has no routes for.
