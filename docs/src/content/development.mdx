# Start Building

This guide walks you through setting up a local development environment and deploying your first cap table. Docker runs MongoDB and the API server, and the product app runs on your machine. Plume Mainnet is the default chain.

## Quickstart

You need Git, Docker, Node.js 24, pnpm, and Foundry. See [Install dependencies](/development/install) if you're missing any.

```bash
git clone --recurse-submodules https://github.com/transfer-agent-protocol/tap-cap-table.git
cd tap-cap-table
pnpm install
REUSE_TAP_FACTORY=1 SKIP_APP=1 pnpm bootstrap
pnpm app:dev
```

Open http://localhost:3000/app and connect a browser wallet. Before you create a company, set `NEXT_PUBLIC_OPERATOR_ADDRESS` in `app/.env.local` to an address or leave it empty. The placeholder bootstrap writes there makes minting fail ([details](/development/setup#frontend-values)).
